# Shipping Hermit for Mac and iPhone

Goal: the smoothest app we can make. So both apps are fully native Swift, with no web view anywhere.
The web demo (hermit-demo.vercel.app) is the design spec; this repo rebuilds it natively.

## Stack

| Part | Choice | Why it's the smoothest |
|---|---|---|
| UI | **SwiftUI** on macOS 26 and iOS 26, AppKit / UIKit where SwiftUI falls short | Native scrolling, text, menus, keyboard and accessibility. 120 Hz on ProMotion screens. Liquid Glass comes for free. |
| Shared code | **HermitKit** Swift package (`Packages/HermitKit`) | One codebase for both apps: `HermitCore` (agent, wallet, chain) and `HermitUI` (design system and screens). |
| Model | **MLX Swift** (Apple's ML framework) with our own small model | Fastest way to run a model on Apple Silicon, same code on Mac and iPhone, unified memory, Metal. |
| Keys | **Secure Enclave + Keychain**, unlocked by **Touch ID / Face ID** | Keys never leave the device or the app. The Approve button is a real biometric prompt. |
| Chain | Swift client for **Base**, USDC first | Matches the demo's Pay flow. Testnet (Base Sepolia) until the signer is reviewed. |
| Mac extras | Menu bar quick-ask, global hotkey, notifications for scheduled payments | Feels like a real Mac app, not a website in a window. |
| Builds | GitHub Actions macOS runner (`.github/workflows/apple.yml`), project generated by **XcodeGen** (`project.yml`) | Our server is Linux. CI builds both apps and renders the screens to PNG for review. |
| Distribution | Mac: signed + notarized download with Sparkle updates (later also the Mac App Store). iPhone: TestFlight, then the App Store. | |

The first versions target macOS 26 and iOS 26 only. That costs us older devices but gives the newest
SwiftUI, Liquid Glass and the fastest MLX on every Mac and iPhone we support.

## Milestones

**M0. Native shell (now)**
- [x] Sidebar, home (crab, greeting, wallet actions, chat box, today), chat with streaming replies.
- [x] The Pay flow from the demo: chart card, Schedule, approval sheet with hazard scan, Touch ID / Face ID, receipt.
- [x] Brand: tokens, Newsreader for headlines (SF Pro for UI text), the mark, app icons.
- [x] CI builds the Mac app and the iPhone app, and renders the screens.
- [ ] iPhone layout from the demo: bottom tab bar, sheets from the bottom.
- [ ] Every remaining page from the demo (Trade, Earn, Payments, Wallets, Projects, Automations, Calendar, Settings).

**M1. Real local chat**: MLX model downloaded on first launch (with progress), streaming replies, works in flight mode.

**M2. Real wallet**: create / import, Secure Enclave, balances on Base, Send through the approval sheet.

**M3. The agent does errands**: scripted replies become tool calls (pay, schedule, swap, deposit); every money move goes through `approve()`.

**M4. Beta**: Developer ID + notarization for the Mac, TestFlight for the iPhone, then the waitlist in waves.

## Needed from the team
1. **Apple Developer Program** ($99/yr). Enroll as an organisation (needs a D-U-N-S number, which can take
   days to weeks, so start now). Without it: no TestFlight, and the Mac app needs right-click > Open.
2. **A Mac with Xcode 26** for day-to-day work on the UI (Xcode previews, the simulator, real Touch ID).
   CI covers builds and screenshots until then.
3. **Model call**: which model ships first (benchmarks in hermit-lab). It gets converted to MLX format.

## Working on it
```bash
brew install xcodegen
xcodegen generate          # writes Hermit.xcodeproj
open Hermit.xcodeproj      # schemes: Hermit (Mac), HermitiOS (iPhone)
cd Packages/HermitKit && SNAPSHOT_DIR=/tmp/shots swift test   # render the screens to PNG
```
